# Service Copy & Semantic SEO (Sherif-Auto)

START → Review Text Nodes → Restructure Hierarchy → Integrate Semantic Keywords → Compress & Check Alt text → END

## Scope & Context

With high reliance on GSAP to move and mask text nodes globally, SEO focus guarantees the content actually resides locally in the DOM and makes sense before JS execution.

## Steps:

1. **RAW HTML CONTENT CHECK:**
   - Disable Javascript. Does the page still present a logical flow of text describing the premium auto upholstery services? If not, the structure is wrong.

2. **SEMANTIC KEYWORD INFILTRATION:**
   - Inject specific niche keywords organically into `<h2>` and `<p>` nodes. (E.g. "Restoration", "Luxury Leather Sets", "Dashboard Repainting"). Avoid keyword stuffing.
   - Never use `display: none;` on text hoping Google crawls it.

3. **IMAGE ALT TEXT INTEGRITY:**
   - Verify every hero and gallery node accurately describes the visual rendering. "Dark grey Dacia Duster interior with gold stitched premium leather seats."
4. **INTERNAL LINKING ARCHITECTURE:**
   - Verify contextual text links connecting Services to Gallery implementations.

5. **TITLE HIERARCHY VALIDATION:**
   - Use `h1` strictly for page essence.
   - Use `h2` for categories.
   - Use `h3` for vehicle cards.
