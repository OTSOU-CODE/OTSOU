---
description: Perform a deep and comprehensive internet search on a specific topic.
---

1. **Analyze the Request**: Identify the core topic and specific details the user is looking for. Break it down into keywords and questions.

2. **Initial Broad Search**:
   - Use `search_web` with general terms to get an overview.
   - Identify key domains, technical terms, or related concepts.

3. **Refine and Iterate**:
   - Based on the initial results, formulate more specific queries.
   - Use `search_web` again for these specific sub-topics.
   - Look for official documentation, forums, or authoritative articles.
   - If code is involved, look for GitHub repositories or StackOverflow discussions.

4. **Deep Dive/Follow-up**:
   - If a specific page looks promising, create a query specific to that site (e.g., `site:docs.python.org "search term"`).

5. **Synthesize**:
   - Compile the gathered information.
   - Cross-reference findings to ensure accuracy.

6. **Report**:
   - Present the findings to the user with clear headings, summaries, and URL citations.
