# Content Strategy (Sherif-Auto)

START → Audit Category/Catalog → Establish SEO Copywriting → Structure Headings → Publish → END

## Scope & Context

Sherif-Auto relies on visual supremacy but requires high-quality SEO text that reinforces the brand's identity as a luxury automotive upholstery provider.

## Steps:

1. **CONTENT AUDIT:**
   - Assess gaps in current galleries (`Dacia`, `Audi`, `BMW`, etc.). Ensures missing brands are queued for 8K rendering.
   - Map text blocks specifically to Vanilla HTML sections (e.g., Hero Taglines, About Us, Footer Disclaimers).

2. **BRAND VOICE & SEO COPYWRITING:**
   - Tone: Premium, expert, established, luxurious.
   - Keywords: Integrate terms like 'Premium Upholstery', 'Dashboard Restoration', 'Custom Leather Seats', 'Automotive Craftsmanship' naturally.
   - Strict rule: Avoid gimmicky or cheap-sounding phrases (e.g., "Cheap prices", "Huge discounts"). Use phrasing like "Unmatched Value" or "Request Consultation".

3. **HTML STRUCTURING:**
   - Apply absolute hierarchy. One `<h1>` per page.
   - Use `<h2>` for section headers (e.g., `Why Choose Us`).
   - Use `<h3>` for cards/components (e.g., `Car Seat Restoration`).

4. **MEDIA STRATEGY (The Core Visuals):**
   - The primary content is the photo gallery.
   - Photos must strictly adhere to the 8K Studio Guidelines found in `docs.md` (e.g., Neutral dark backgrounds, realistic lighting).

5. **REVIEW & PUBLISH:**
   - Check contrast of text layered over images ensuring legibility (implementing CSS gradients underneath).
   - Verify Mobile readable font-sizes using CSS `clamp()`.
