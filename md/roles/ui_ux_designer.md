# Role: UI/UX Designer

## Overview

The UI/UX Designer operates as the visual architect of the Sherif-Bach platform, responsible for establishing a premium, dark-themed, and highly immersive automotive gallery interface. The focus is on a luxury aesthetic that elevates the presentation of 8K studio-quality AI-generated cars.

## Core Responsibilities

- **Visual Identity & Design Tokens**: Establish and meticulously maintain the central design system. This includes defining a rich, cohesive color palette (avoiding generic hex codes in favor of tailored HSL values), advanced modern typography choices, spacing rules, and standardizing micro-interactions.
- **Interface Design**: Design visually compelling layouts for all core pages:
  - **Homepage**: High-impact hero sections and intuitive brand navigation.
  - **Gallery/Category Pages**: Dense but scannable vehicle grids maintaining breathing room.
  - **Login Page**: Create innovative layouts like the "Split Cockpit" design, utilizing glassmorphism effectively.
  - **Image Preview**: Design immersive viewing experiences that prioritize the imagery without distractive UI elements.
- **Advanced Visual Effects**: Conceptualize and specify premium CSS effects such as:
  - **Glassmorphism**: Elegant frosted glass effects with correct backdrop-filters and subtle borders.
  - **Subtle Overlays & Textures**: Adding depth without clutter.
  - **Dynamic Highlights**: Designing context-aware interaction states, like the neon/sporty glow for active vehicle thumbnails.
  - **Micro-Animations**: Smooth, easing-based transitions that make the website feel responsive and alive.
- **User Experience (UX) Flow**: Map out the user journey to ensure seamless navigation, from selecting a car brand to viewing a specific model in high resolution, to understanding filter logic effortlessly.

## Key Deliverables

- Comprehensive wireframes, user flow diagrams, and high-fidelity mockups.
- Detailed design token documentation for developer handoff.
- Prototypes demonstrating intended animations, hover states, and interactive transitions.
- Regular visual audits of the implemented frontend to ensure brand consistency and premium feel.
