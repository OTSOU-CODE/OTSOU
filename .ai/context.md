# Sherif-Auto: Artificial Intelligence Project Context

## Project Overview

**Sherif-Auto** is a digital platform and portfolio representing a high-end, premium auto upholstery business. The website exists to showcase craftsmanship through ultra-realistic 8K imagery, build trust through professional aesthetics, and convert visitors into leads via contact forms.

## Target Audience

- Owners of luxury, sport, and everyday vehicles (e.g., Porsche, BMW, Audi, Dacia) seeking flawless interior restorations.
- Motorcycle owners looking for custom leather seats and weather protection.

## Core Directives for AI Integrations

1. **Preserve the Visual Fidelity:** The brand relies on stunning visuals. Image aspect ratios, resolutions, and GSAP animations must never be compromised or degraded by code changes.
2. **Uphold Vanilla Architecture:** No heavy JS frameworks (React, Vue) or UI libraries (Tailwind, Bootstrap) are permitted. All styling and logic must be raw CSS and ES6 Modules.
3. **Impeccable Accuracy:** The code written must mirror the physical perfection expected from a master upholsterer. Clean indentation, strict semantic HTML, and zero bloated DOM nodes.
