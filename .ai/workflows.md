# AI Agent Workflows Reference

The Sherif-Auto project maintains a strict set of 19 operational workflows that dictate everything from Sitemap Creation to Security Implementations.

## Workflow Directory Location

All specific operational workflows are located in the following directory:
`[Project Root]/.agent/workflows/`

## Available Workflow Categories

When undertaking a complex task, AI agents MUST refer to the specific files within `.agent/workflows/` rather than inventing operational pipelines:

1. **Information Architecture (2.x)** - Sitemap, Navigation, URL Structures.
2. **Design (3.x)** - Wireframing, CSS Variable maintenance, GSAP Polish.
3. **Frontend Development (4.x)** - Vanilla Form implementations, ES6 Components, State Management without Redux.
4. **Backend Development (5.x)** - Firebase NoSQL configurations and API integrations.
5. **Content (6.x)** - SEO copywriting and WebP image downgrading strategies.
6. **Performance (7.x)** - DOM Node limits, Layout Thrashing prevention, Cache rules.
7. **Accessibility (8.x)** - Custom ARIA roles for GSAP Menus, Keyboard trap prevention.
8. **SEO (9.x)** - Static HTML tag injections, Schema JSON-LD.
9. **Testing (10.x)** - Pre-launch sanity checks and logical QA.
10. **Security & Docs (14.x / 15.x)** - Firebase Rule locks and JSDoc requirements.

_Always read the specific customized workflow file before executing multi-file codebase changes._
